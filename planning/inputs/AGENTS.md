# Planning Inputs AGENTS.md

This folder holds source material that applies to **every** planning phase: course requirements, grading rubrics, deadlines, team agreements, and any constraint that outlives a single phase. Material that matters only to one phase goes in that phase's `inputs/` folder instead, for example `architecture/inputs/`.

Inputs are what the plans are built from. Plans cite inputs, and inputs never cite plans.

## Rules for Agents

- **Read-only.** Don't edit, rename, move, or delete any file here except this `AGENTS.md`. Only humans add or replace inputs.
- **Keep the index current.** This `AGENTS.md` is the only file here that agents may edit. When you find a file that isn't listed in the index below, read it and add a row. If a listed file is gone, remove its row. Don't change anything else in this file without the human you're working for asking you to.
- **Cite by path and location.** When a plan relies on an input, cite the file and the page or section, for example `inputs/syllabus.pdf p.3`.
- **Don't fill gaps yourself.** If an input is unclear, incomplete, or seems out of date, record an Open Question. Its owner is the human you're working for, or the group.

## Precedence

- **Inputs here are hard constraints.** That applies to course requirements, rubrics, and deadlines. A plan or decision that breaks one is wrong, even if it's Accepted. Flag it to a human.
- **When a phase input conflicts with an input here,** for example a design in `architecture/inputs/` that misses a course requirement listed here, record an Open Question. Don't silently follow either one.
- **When two inputs here disagree,** the newer one wins only if a human says so in the index's Notes column. Otherwise, record an Open Question.

## Adding or Replacing Inputs (for humans)

- **Never overwrite a file.** Add the new version alongside the old one, with a date or version in the name, for example `rubric-2026-11-20.pdf`, and note in the index which one is current.
- **Prefer formats agents can read:** PDF, Markdown, plain text, or `.drawio`. Text in images is harder to cite.
- **Tell the agent** in the next session that something was added, so the index is updated.
